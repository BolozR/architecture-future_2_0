# Агрегаты

| контекст / агрегат | ключ | границы и инварианты |
| --- | --- | --- |
| пациентский поток / Patient | patient_id | регистрация и локальный статус; внешняя система + external_id уникальны; ФИО остаётся внутри домена |
| пациентский поток / Appointment | appointment_id | запись на слот и статус посещения; занятый слот нельзя выдать повторно; отменённый приём нельзя завершить |
| клиническая помощь / MedicalRecord | record_id | принадлежит одному patient_id; изменения версионируются; доступ проверяется по роли и основанию |
| ИИ / AnalysisJob | analysis_id | одна задача на request_id; результат публикуется только после сохранения; завершённую задачу не запускаем заново тем же ключом |
| кредитование / LoanAgreement | agreement_id | один договор на принятую заявку; сумма положительна, валюта фиксирована; подписание возможно после одобрения |
| платежи / Payment | payment_id | idempotency_key уникален; сумма в минимальных денежных единицах; один подтверждённый платёж не учитывается повторно |
| управленческие финансы / Invoice | invoice_id | сумма строк совпадает с итогом; признание выручки связано с оказанной услугой; возврат корректирует исходный период по правилам учёта |
| фарма / Shipment | shipment_id | партии и количества; нельзя подтвердить больше отгруженного без отдельной корректировки |
| оборудование / Device | device_id | серийный номер уникален; обслуживание меняет статус устройства; телеметрия не содержит измерений пациента |
